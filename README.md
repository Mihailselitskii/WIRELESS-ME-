# Wireless ME

Мод для Minecraft (NeoForge) с беспроводными ME-кабелями для **Applied Energistics 2**. Соединяйте блоки сети ME на любом расстоянии, без затрат энергии и с автоматической прогрузкой чанков.

## Возможности

- Беспроводная связь между двумя точками сети ME на любое расстояние (ограничение задаётся в конфиге).
- Связь не потребляет энергию.
- Чанки на концах связи прогружаются автоматически, поэтому сеть не «засыпает», когда рядом нет игрока.
- Простое подключение: два клика инструментом.

## Требования

| Компонент | Версия |
|-----------|--------|
| Minecraft | 26.2 |
| NeoForge | 4+ |
| Applied Energistics 2 | 26.2+ |

## Предметы

### Wireless ME Cable (Беспроводной ME-кабель)

Блок, который подключается к сети ME и служит концом беспроводной связи.

```
 R
CBL
SSS
```

| Символ | Предмет |
|--------|---------|
| R | Беспроводной приёмник (`ae2:wireless_receiver`) |
| C | Процессор вычислений (`ae2:calculation_processor`) |
| B | Беспроводной усилитель (`ae2:wireless_booster`) |
| L | Логический процессор (`ae2:logic_processor`) |
| S | Блок небесного камня (`ae2:sky_stone_block`) |

### Wireless Linker (Беспроводной Соединитель)

Инструмент для создания и разрыва связей между кабелями.

Рецепт (бесформенный): `ae2:certus_quartz_wrench` → 1 соединитель.

## Как пользоваться

1. Поставьте беспроводные кабели в двух местах и подключите каждый к своей сети ME.
2. Возьмите Соединитель и нажмите **ПКМ** по блоку A. Точка будет записана.
3. Нажмите **ПКМ** по блоку B. Связь установлена.
4. Чтобы разорвать связь, нажмите **Shift + ПКМ** по блоку.

Если блок B слишком далеко, соединитель сообщит об этом. Лимит можно увеличить в конфиге.

## Конфигурация

В конфиге мода доступны параметры:

| Параметр | Описание |
|----------|----------|
| `maxRange` | Максимальная дальность связи |
| `chunkRadius` | Радиус прогрузки чанков вокруг концов связи |
| `maxLinksPerBlock` | Максимальное число связей у одного блока |

## Установка

1. Установите NeoForge для Minecraft 26.2.
2. Установите Applied Energistics 2 нужной версии.
3. Положите `wireless-me-1_0_0.jar` в папку `mods`.
